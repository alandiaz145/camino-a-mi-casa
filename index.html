Detrás del objetivo

Quién soy

Soy Alan, DJ, productor musical, diseñador gráfico y editor de video. Este proyecto documenta el camino hacia una casa propia, pero también todo lo que quiero construir alrededor de ella: música, trabajo, oportunidades, aprendizaje y un espacio desde el barrio para crear con otras personas.

No busco mostrar un camino perfecto. Quiero mostrar el proceso real: trabajar, equivocarme, cambiar, aprender y seguir avanzando.

El sentido de ayudar

¿Por qué aportar?

No creo que una vida tenga que medirse solamente por cuánto somos capaces de sacrificarnos. Este proyecto busca mostrar qué puede pasar cuando muchas ayudas pequeñas empujan una idea real. Primero quiero construir estabilidad para poder seguir creando y después devolver esa energía: generar trabajo, apoyar artistas y, con el tiempo, colaborar con proyectos sociales y refugios de animales.

Aportar no es una obligación. Es una forma de acompañar el camino si lo que estoy construyendo te representa.
