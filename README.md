# Camino a mi casa

Panel personal responsive para convertir la meta de una casa en objetivos diarios, semanales y mensuales.

## V2
- Meta y plazo editables
- Ingresos y retiros
- Productos/servicios con precio, costo y ganancia real
- Escenarios automáticos de venta
- Galería de referencia
- Diseño mobile-first
- Persistencia local en el navegador

> Esta versión guarda los datos en localStorage. En una siguiente etapa conviene agregar una base de datos para sincronizar teléfono y PC.
